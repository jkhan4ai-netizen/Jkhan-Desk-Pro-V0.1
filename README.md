# Jkhan Desk Pro 🚀

Jkhan Desk Pro — это многофункциональный дашборд для управления проектами, задачами, финансами и временем, разработанный в премиальном Apple-style дизайне (Glassmorphism).

## 🌟 Возможности

*   **Управление проектами (Kanban)** — интерактивная доска для ведения проектов с Drag-and-Drop функционалом.
*   **CRM и Клиенты** — база данных ваших клиентов и история взаимодействия с ними.
*   **Финансы и Аналитика** — учет доходов и регулярных расходов, автоматические графики динамики прибыли (Recharts).
*   **Pomodoro Таймер** — встроенный таймер для работы по технике Помодоро с настраиваемыми интервалами.
*   **Список желаний (Wishlist)** — отслеживание финансовых целей и прогресса накоплений.
*   **Интеграция с Telegram** — автоматическая привязка Telegram-бота через Webhook для получения персональных уведомлений о дедлайнах и статусах.

## 💻 Технологический стек

*   **Фреймворк:** [Next.js 15 (App Router)](https://nextjs.org/)
*   **Язык:** TypeScript
*   **Стилизация:** Tailwind CSS + UI-компоненты (shadcn/ui)
*   **База данных:** [Supabase](https://supabase.com/) (PostgreSQL + Row Level Security)
*   **Анимации:** Framer Motion, dnd-kit

## 🛠 Запуск проекта локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
cd "НАЗВАНИЕ_РЕПОЗИТОРИЯ"
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта и добавьте следующие ключи:
```env
NEXT_PUBLIC_SUPABASE_URL=ваш_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_supabase_anon_key
TELEGRAM_BOT_TOKEN=токен_вашего_телеграм_бота
```

### 4. Настройка базы данных
Вам нужно выполнить SQL-миграции в вашем проекте Supabase через SQL Editor:
1. Выполните скрипт `supabase/migrations/001_initial_schema.sql` (создание таблиц)
2. Выполните скрипт `supabase/migrations/002_wishlist.sql` (добавление вишлиста)
3. Выполните скрипт `supabase/migrations/003_telegram.sql` (интеграция телеграм)

### 5. Запуск сервера разработки
```bash
npm run dev
```
Проект будет доступен по адресу: `http://localhost:3000`

## 🌍 Публикация на Vercel и Telegram Webhook

При публикации проекта на Vercel не забудьте прописать переменные окружения в настройках проекта на сайте Vercel.

Для работы Telegram-бота необходимо привязать Webhook:
Откройте в браузере ссылку (заменив переменные на ваши):
```text
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<ВАШ_САЙТ_НА_VERCEL>/api/telegram/webhook
```
