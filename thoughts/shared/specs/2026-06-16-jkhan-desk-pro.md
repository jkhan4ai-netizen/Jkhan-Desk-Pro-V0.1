# Jkhan Desk Pro — Спецификация продукта

## Executive Summary

**Jkhan Desk Pro** — персональная система управления бизнесом для мультидисциплинарного дизайнера (motion-дизайн, графика, видеомонтаж, UI/UX). Система объединяет управление проектами, CRM, бухгалтерию, трекинг времени и аналитику в единый инструмент с премиальным интерфейсом.

**Для кого:** Один пользователь — фрилансер/дизайнер, работающий с микс-клиентами (B2B + B2C).

**Зачем:** Заменить хаос «всё в голове» на структурированную систему, которая показывает реальную картину бизнеса — от дедлайнов до чистой прибыли.

---

## Problem Statement

### Текущая боль
- **Нет системы:** Все процессы управляются по памяти и интуиции
- **Финансовый туман:** Непонятно, сколько реально зарабатывается после вычета расходов (подписки, софт, AI-сервисы, рассрочки)
- **Потерянные долги:** Клиенты не доплачивают — нет системы отслеживания
- **Нестабильный поток:** От 1 до 10 проектов одновременно — нужна система, которая масштабируется в обе стороны
- **Ценообразование вслепую:** Нет данных о реальной стоимости часа работы

### Что произойдёт, если не построить
Продолжение работы «по памяти» приведёт к:
- Потере денег на забытых долгах
- Переработке на проектах (не зная реальных часов)
- Невозможности масштабироваться
- Отсутствию понимания, какие услуги прибыльны

## User Persona

### Jkhan — мультидисциплинарный дизайнер
- **Возраст:** 20-35 лет
- **Локация:** Узбекистан
- **Специализация:** Motion-дизайн, 2D/3D анимация, графический дизайн, видеомонтаж, UI/UX
- **Инструменты:** After Effects, Cinema 4D, Blender, Figma, Premiere Pro
- **Клиенты:** Микс B2B (компании, студии) и B2C (блогеры, малый бизнес)
- **Поток:** Нестабильный — от 1 до 10 параллельных проектов
- **Оплата:** Гибкая — фикс, почасовая, многоэтапная
- **Валюты:** UZS (основная), RUB, USD
- **Языки интерфейса:** Узбекский + Русский
- **Технический уровень:** Продвинутый пользователь, но не программист

## User Journey

### Утренний ритуал (главный сценарий)
```
Открыл приложение
  → Dashboard: что горит сегодня? (проекты с близкими дедлайнами)
  → Что нужно сделать? (задачи на сегодня)
  → Финансовая сводка (доход, долги)
  → Запустил Pomodoro → начал работу над проектом
  → Остановил таймер → система записала время
  → Завершил проект → остаток долга автоматом в "Мне должны"
  → Конец дня: быстрый обзор продуктивности
```

### Новый проект (ключевой сценарий)
```
Новый клиент написал в Telegram
  → Создаю карточку клиента (или выбираю существующего)
  → Создаю проект → привязываю к клиенту
  → Указываю: тип, цена, валюта, предоплата, дедлайн
  → Добавляю ссылки: референсы, облачный диск с исходниками
  → Проект в статусе "Новый"
  → Получил предоплату → отмечаю в системе
  → Начал работу → статус "В работе" → запускаю таймер
  → Клиент просит правки → счётчик правок +1
  → Завершил → статус "Готов"
  → Клиент оплатил остаток → статус "Оплачен" → Архив
  → Если НЕ оплатил → остаток → "Мне должны"
```

## Functional Requirements

> See full specification in the artifact: jkhan-desk-pro-specification.md

### Модули системы:
1. 📋 **Управление проектами** — CRUD, статусы, финансы, медиа-ссылки
2. 👥 **CRM** — клиенты, LTV, статусы, аналитика
3. 💰 **Финансы и Долги** — доходы, расходы, подписки, долги в обе стороны
4. 🛒 **Wishlist** — покупки по профессии с приоритетами
5. ⏱ **Тайм-менеджмент** — таймер + Pomodoro + расчёт стоимости часа
6. 📈 **Аналитика и Дашборд** — KPI, графики, ургентность
7. 🤖 **Уведомления** — внутренние + Telegram (PRO)
